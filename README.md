## Projetos em Destaque

* **Análise de Salários em Ciência de Dados:** Estudo exploratório de mais de 10.000 registros do mercado de dados utilizando Python, acompanhado de dashboards interativos em Power BI e artigo científico com modelagem preditiva.
* **Análise de Contratos Públicos (PNCP / Lei 14.133):** Coleta via API e análise comparativa do uso do Sistema de Registro de Preços (SRP) em licitações públicas entre 2024 e 2025.
* **Análise de Churn e Sentimentos:** Processamento de linguagem natural (NLP) com VADER e análise de dados em Python para identificar e categorizar motivos de cancelamento a partir de feedbacks de clientes.
* **DSA AI Coder:** Assistente de programação interativo desenvolvido em Python utilizando Streamlit e integração com a API da Groq.
* **Gerador de Catálogo OPDS:** Script em Python para organização automatizada de bibliotecas digitais e geração dinâmica de feeds XML (OPDS) para leitura em dispositivos e-ink.
* **Swiss Wallet (TCC):** Aplicação mobile (React Native) e web integrada a back-end Java e APIs RESTful para gestão de vendas e empréstimos de livros acadêmicos.
